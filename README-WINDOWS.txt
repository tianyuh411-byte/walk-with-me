WALK WITH ME — Windows x64

1. Extract the ENTIRE ZIP to a normal folder. Do not run inside the ZIP viewer.
2. Double-click "Walk With Me.exe". Keep the adjacent DLLs and game folder.
3. Click "Let's walk". WASD / arrow keys move. R starts or ends recording.
   T resets the room. Esc pauses. "Sound off" enables synthesized sound effects.
   Click "简体中文" at the top right for the complete Simplified Chinese UI.
   Click "English" to switch back. The language choice is remembered locally;
   first launch defaults to English. Switching does not reset your current room.

Requirements: 64-bit Windows 10/11; .NET Framework 4.8; Microsoft Edge WebView2
Evergreen Runtime (normally already installed on current Windows).
Runtime download: https://developer.microsoft.com/microsoft-edge/webview2/

No Node.js, local server, login or internet connection is needed to play.
This is an actual Windows desktop application with a local WebView2 renderer.
It does not open Edge as a browser tab. It is not a self-contained runtime bundle.

Keyboard: WASD / arrows — move. R — record / finish. T — reset. Esc — pause.
Recordings reset the room at both ends and stop at 12 seconds. One echo replays
your exact timed route, then stays at the endpoint. No looping. Both actors can
hold plates. Only you can exit. A bridge stays open 2.4 seconds after release.
If it fades underfoot, the whole attempt resets; watch the flashing stripes.
Switching windows pauses the game; click "Keep walking" to resume.

Current-room progress is saved locally. An unfinished recording is not saved.
Optional fallback: game/index.html also runs offline in a modern browser.
Touch controls exist in the browser edition; Windows is the tested desktop target.

This game contains AI-generated content. OpenAI Codex (GPT-6) assisted with
game code, level design, English/Chinese text, procedural graphics and test/build tools.
All sound effects are synthesized. No official theme recording is included.
See CREDITS.md, WEBVIEW2-LICENSE.txt and WEBVIEW2-NOTICE.txt for attribution.

Known limitations: independent human playtesting of the 5–8 minute duration is
pending; theme-music listening / interpretation is pending; no Mac binary.
Windows SmartScreen may flag this unsigned indie executable. No signature is
claimed. A clean Windows machine without the listed runtimes has not been tested.
